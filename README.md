# Sahithi Chukka — 3D Developer Portfolio

A responsive, high-performance developer portfolio built with modern Web standards, featuring interactive Three.js 3D visualizers, dynamic theme switching, an interactive skills constellation, and detailed project case studies.

## 🛠️ Technology Stack

- **Core:** HTML5, Modern JavaScript (ES6+), Vanilla CSS Design System
- **3D & Graphics:** Three.js, WebGL Canvas
- **Bundler & Tooling:** Vite, Node.js
- **Deployment:** Vercel Edge Network

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
